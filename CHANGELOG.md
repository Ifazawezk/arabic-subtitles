# Changelog

## 0.1.0

First release.

- Offline Arabic transcription with faster-whisper, GPU first with automatic CPU fallback.
- Cue builder with Arabic line breaking, reading speed limits and merge and split rules.
- SRT, VTT, ASS, TXT and JSON output, and rebuilding subtitles from JSON without the model.
- Burn-in with correct right-to-left rendering and a bundled Arabic font.
- English translation track.
- Filter for credit lines that Whisper invents on silence.
- Local web UI with a subtitle editor.
- Public evaluation on openly licensed Arabic audio.
